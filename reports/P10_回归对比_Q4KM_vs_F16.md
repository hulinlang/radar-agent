# P10-A5 · 量化回归对比：Q4_K_M vs F16（同引擎、同题集、同判分口径）

> 2026-10-06 ｜ 判分口径 v3（与 P5/P7 同一把尺子）｜ 引擎：llama-server b10951（Windows Vulkan）
> 样本：冻结评测集全量 200 题 × A（无工具）/ B（完整 ReAct 系统）两组
> 证据文件：`reports/P7_端到端评测_p10gguf200.md`（Q4_K_M）、`reports/P7_端到端评测_p10f16_200.md`（F16）
> 设计说明：HF bf16 基线因 9h 未完成被放弃（见 docs/19 §4.2）；本对照**只变量化一档**，
> 是"Q4_K_M 丢了多少精度"的最干净回答。

## 1. 质量对比（核心结论）

| 指标 | F16（未量化） | Q4_K_M | Δ（Q4 − F16） |
|---|---|---|---|
| A 综合得分 | 0.375 | 0.360 | **−0.015** |
| A 3-gram F1 | 0.298 | 0.301 | +0.003 |
| A 拒答正确率 | 100.0% | 100.0% | 0 |
| **B 综合得分** | 0.340 | 0.305 | **−0.035** |
| B 3-gram F1 | 0.331 | 0.286 | −0.045 |
| B 数值命中 | 56.6% | 51.0% | −5.6pp |
| B 拒答正确率 | 78.9% | 78.9% | 0 |
| B 引用坏引用数 | 0 | 0 | 0 |

**结论**：
1. Q4_K_M 有**轻微但可测**的退化：B 组综合 −0.035（其中数值命中 −5.6pp 是主要来源——
   计算题对数值精度最敏感，符合预期）；A 组差异在噪声量级（±0.015）。
2. **没有系统性崩塌**：拒答行为、引用溯源（0 坏引用）、工具调用链路全部保留。
3. 对照 P7 的检索净收益（−0.035 ~ −0.075 量级），量化退化与"加不加 RAG"的影响同量级——
   **对演示场景可接受；若用于更高风险场景，建议 Q8_0**（Pareto 第三档，未测，见 docs/17 S8）。

## 2. 性能对比（§5.9 口径：服务端 timings，逐请求）

| 档位 | decode tok/s（均值） | per-token P50 / P99 | prefill P50 / P99 | 200 题墙钟 |
|---|---|---|---|---|
| Q4_K_M | **142 / 128**（A/B 组） | 7.1 / 8.4 ms | 29 / 72 ms | **7 min** |
| F16 | 9.9 / 9.8 | 102.3 / 103.9 ms | 119 / 149 ms | 69 min |

⚠️ **F16 的性能数字不代表 F16 的真实水平**：F16 权重 3.44GB + bge-m3（2.12GB）+ 桌面占用，
在 8GB 卡上超出显存预算，llama-server 实际发生了层拆分/显存争抢（未逐层核实，存疑标注）。
质量分数不受速度影响（greedy 确定性解码），本报告的质量结论不受影响；
性能结论只取"**Q4_K_M 在此机 feasible 且快，F16 在此机不可行**"这一条。
WSL2 CUDA 路径的 Q4_K_M 实测 118.6 tok/s（短请求冒烟口径），与 Vulkan 142 tok/s 同量级。
