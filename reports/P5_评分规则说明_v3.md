# P5 对比评测 · 评分规则说明（判分口径 v3）

> 配套文件：`scripts/p5_eval_report_v3.py`（判分实现）
> 对比结果：`reports/P5_对比评测_口径v3_vis200.html`
> 指标明细：`reports/P5_对比指标_v3_vis200.json`
> 评测对象：基座 Qwen3-VL-2B-Instruct vs LoRA 微调后（`outputs/p5_lora/sft1074_vis200_e3`）
> 评测集：冻结的 120 条（教材 75 + 视觉 17 + 毫米波 28），**未参与训练，也未用于任何调参**

---

## 0. 一句话总览

没有任何单一指标能同时衡量「答得对」和「答得像」。所以本报告用 **两套并行判分**：

| 套 | 指标 | 回答的问题 |
|---|---|---|
| **精确判分** | `score`（数值 / 字母 / 拒答三分支） | **答对了没有**（客观对错） |
| **语义判分** | `F1` / `P` / `R` / `num_hit` | **答得有多接近**（部分正确也能体现） |

两者必须一起看。只看 `score` 会把"答对一半"和"完全答错"混为一谈；只看 `F1` 会把"数值全错但话术像"判成高分（v3 新增 `num_hit` 正是为了堵这个洞，见 §3.3）。

---

## 1. 指标清单

| 指标 | 测什么 | 取值 | 适用题型 | 主要局限 |
|---|---|---|---|---|
| `score` | 客观对错 | 0 / 1 | calc、choice、regime_trap、unanswerable | 无部分分 |
| `F1` | 3-gram 语义重叠 | 0~1 | 全部 | 对数值错误不敏感 |
| `P`（精确率） | 输出中有多少片段在答案里 | 0~1 | 全部 | 越啰嗦越低 |
| `R`（召回率） | 答案中有多少片段被覆盖 | 0~1 | 全部 | 漏内容会降 |
| `num_hit` ⭐ | 数值命中率 | 0~1 | 含数值的题 | 不检查单位与语义 |
| `ratio` | 长度比 | 倍数 | 全部 | 1.0 最理想 |
| `format_fail` | 格式失效 | 0/1 | 非选择题 | 只测"答成字母"一种 |
| `F1_raw` | v2 原始口径 F1 | 0~1 | 全部 | 仅作口径对照 |

---

## 2. 输入与预处理

每条样本有 `prediction`（模型输出）与 `reference`（标准答案，编译期写死，不随模型变）。

**v3 的 F1 在切 3-gram 之前先做标点归一化**（`norm()`）：

```
去掉：空白 + 中英文标点 + LaTeX 符号（$ \ { } 等）
```

⚠️ 这一步在 v2 里 **从未生效**——`norm()` 定义了但一次都没被调用（实测 `norm(` 调用次数 = 0），
导致 `$P_d=90\%$` 这类 LaTeX 标记进了 3-gram 分母，额外惩罚了"用 LaTeX 写答案"的风格。
v3 修正后仍保留 v2 口径的 `F1_raw` 作对照，两者的差就是风格惩罚的大小（实测 1~2 个百分点，
方向不一致：视觉 +1.8、可答题 −0.5）。

## 3. 逐条规则与真实算例

### 3.1 `score` —— 精确判分（按 `answer_check.type` 走三个分支）

#### (a) `numeric`：计算题（calc，26 条）

```
从 prediction 里正则抽出所有数字
若存在 x 使 |x − value| ≤ max(tol, |value| × 2%)  → 1.0
否则 → 0.0
```

`value` 与 `tol` 来自参数池的 eval 半边（不是模型算的）。
容差取"显式 tol"与"2% 相对误差"的较大者。

> 例：带宽 4 GHz 的距离分辨率，参考值 0.0375 m。模型输出 0.0375 → 1.0；输出 0.075 → 0.0。

#### (b) `refusal`：不可答题（unanswerable，12 条）

```
prediction 中出现任一拒答标记 → 1.0，否则 0.0
拒答标记 = [无法回答, 未找到, 没有找到, 没有相关, 资料中未, 无法给出, 不能回答]
```

> 这条测的是**防幻觉**。基座在这 12 条上得 0.000（全部编造答案），微调后 0.917（12 条中 11 条正确拒答）。

#### (c) `choice`：选择题（choice 14 + regime_trap 7 = 21 条）

```
优先匹配显式声明：/(?:选\s*|最终答案\s*[：:]\s*|答案\s*[：:]\s*)([A-D])\b/
找不到再退化匹配：整行只有字母（旧版模型只输出 "最终答案：A"）
提取到的字母 == 正确选项 → 1.0
```

兼容新旧两种输出风格，因为答案模板已从 `最终答案：A` 改为
`选 A，因为…\n最终答案：A`。

#### 随机基线检验（防止把"蒙对"当"学会"）

4 选 1 的随机基线是 25%。做二项检验 `P(X ≥ k)`，`k` = 答对条数：

```
本次：19 / 21 = 90%，p = 0.000 → 显著高于随机
```

⚠️ 修复 options 渲染之前，同一组题只有 6/21（29%），p = 0.433 **不显著**——
那时选择题题面里根本没有选项，模型只能盲猜，结论不可用。

---

### 3.2 `F1` / `P` / `R` —— 3-gram 语义重叠（全部题型）

```
A = prediction 的 3-gram 集合
B = reference 的 3-gram 集合
P = |A∩B| / |A|        输出里有多少片段能在答案里找到（越啰嗦越低）
R = |A∩B| / |B|        答案里有多少片段被输出覆盖（漏内容会降）
F1 = 2PR / (P + R)
```

3-gram = 去标点后按字符滑窗取连续 3 字。取 3 是权衡：2-gram 太宽松（单字碰巧重复就命中），
4-gram 太严格（换一种说法就全丢）。

**真实算例**（evv_000401，读检测概率曲线）：

| | 文本 | P | R | F1 |
|---|---|---|---|---|
| 参考 | 参数框标明探测距离 Pd−90% 为 19.1 km；曲线在约 20 km 后急剧下降，到约 26 km 处降为 0。 | — | — | — |
| 基座 | 根据图中检测概率曲线，探测距离 $P_d = 90\%$ 对应的点为 $19.1$ km… | 0.141 | 0.196 | **0.164** |
| 微调 | 探测距离 Pd=90% 为 19.1 km；曲线在约 20 km 后急剧下降，到约 30 km 时已降到 10% 以下。 | 0.644 | 0.630 | **0.637** |

注意微调这条**把 26 km 读成了 30 km、把"降为 0"说成"10% 以下"**，数值是错的，
但 F1 给了 0.637 —— 这就是 §3.3 要解决的问题。

**为什么要同时报 P 和 R**：F1 单值无法区分"变精炼"（P↑R≈）与"漏内容"（R↓）。
本轮 P 从 0.153→0.354、R 从 0.171→0.314 **双升**，说明是真的变好，不是靠缩短刷分。

### 3.3 `num_hit` —— 数值命中率（⭐ v3 新增，读数题的独立判据）

```
rn = 从 reference 抽出的数值列表
pn = 从 prediction 抽出的数值列表
若 rn 为空 → 返回 None（该题不参与均值，避免稀释）
num_hit = |{v ∈ rn : ∃x ∈ pn, |v−x| ≤ max(|v|×2%, 1e-9)}| / |rn|
```

处理细节：先把 Unicode 减号 `−`（U+2212）、破折号统一成 ASCII `-`，
否则参考里的 `−100` 会被切成 `100`，符号丢失导致比对失真。

**为什么必须有它** —— 定量实验（句式一字不改，只换数字）：

| 预测 | F1 |
|---|---|
| 照抄参考 | 1.000 |
| 19.1 / 20 / 26 km 全改成 88.8 / 91 / 97 km | **0.717** |
| 只把关键距离 19.1 → 88.8 | **0.870** |
| 完全不相关 | 0.000 |

数值全错还能拿 0.717，说明 **F1 测的是"用词像不像"，不是"读得对不对"**。

**本轮结果**：

| 分组 | 含数值题数 | 基座 | 微调 | Δ |
|---|---|---|---|---|
| 可答题 | 73 | 0.395 | 0.533 | **+0.139** |
| 文本题 | 60 | 0.432 | 0.593 | **+0.161** |
| 视觉题（读数类） | 13 | 0.223 | 0.256 | **+0.033** |

**背离检测**（F1 涨了，数值是否也涨）：

| 分组 | F1 Δ | num_hit Δ | 判定 |
|---|---|---|---|
| 文本题 | +0.207 | +0.161 | 一致（真实提升） |
| 视觉题 | +0.033 | +0.033 | 一致但幅度仅为文本 1/5 |

→ **结论：视觉"读数"能力几乎没提升。** readout 题型的数值命中率 0.467 → 0.467，**一条没变**。

---

### 3.4 `ratio` —— 长度比

```
ratio = len(prediction) / len(reference)
```

不用绝对字数：绝对量会被题型构成混淆（拒答题天然极短），且无法判断"短得对不对"。
`1.0` 表示与标准答案等长。

| | 基座 | 微调 |
|---|---|---|
| 可答题长度比 | 1.54× | **0.89×** |

**自检（防止"变短=刷分"）**：F1 对过短严厉、对冗长宽容 —— 把输出截到参考答案的 25% 只得
F1 0.333，而注入 8 倍无关废话仍有 0.548。所以本口径下变短是**扣分项**，F1 大涨不可能靠变短刷出来。

---

### 3.5 `format_fail` —— 格式失效（v1 漏掉的独立失效模式）

```
若 task ∉ {choice, regime_trap}
且 prediction 去掉首尾空白后能匹配 ^(?:最终答案[：:])?([A-D])$
且 len(prediction.strip()) ≤ 20
→ 判为格式失效
```

**意义**：开放题被答成单个字母，是**输出格式失效**，不是能力差。v1 把它算进能力得分，
导致 concept 被误判为"变差"。这类样本必须单列，并可剔除后重算。

本轮：**基座 0 条 / 微调后 0 条**（options 渲染修复 + 答案改为"选 A，因为…"后彻底消除）。

## 4. 分组口径

| 分组 | 定义 | n |
|---|---|---|
| 全部 | 评测集全量 | 120 |
| 可答题 | `task ≠ unanswerable` | 108 |
| 可答题且格式未失效 | 上者再剔除 `format_fail` | 108 |
| 拒答题 | `task = unanswerable` | 12 |
| 文本题 / 视觉题 | 按 `modality` 拆分 | — |

**小样本规则（v3 新增）**：`n < 5` 的题型组在表中灰显并标注「不作结论」。

原因：readout 只有 3 条，v2 曾把它的 +0.193 单列成亮点，实为 1 条 evv_000401 拉动
（0.164 → 0.637，贡献 +0.158）。n=3 的均值不能支撑任何结论。

本轮 n<5 的组：clarify(2)、compare(4)、readout(3)、trend(2)。

| 版本 | 修正 | 触发证据 |

| v1 → v2 ① | 长度改用「长度比」 | 绝对字数被题型构成与拒答题混淆 |
| v1 → v2 ② | 补报 P / R | F1 单值无法区分"变精炼"与"漏内容" |

| **v2 → v3 ⑥** | **n<5 标注不作结论** | readout 仅 3 条却被单列为亮点 |

## 6. 已知局限（本报告不做的事）

1. **不做显著性声称**。120 条上 1 条 ≈ 0.83 个百分点；分题型后每组仅数条至二十余条。
   只报方向与幅度。唯一做了统计检验的是选择题（有随机基线可参照）。
2. **`num_hit` 不检查单位与语义**。模型写"19.1"但单位错了，仍算命中；它只保证数值出现。
   与 `score`（calc 的严格数值判分）互补，不替代。
3. **3-gram F1 对同义改写不宽容**。换个说法（"急剧下降"→"快速衰减"）会掉分，
   所以它衡量的是"表述贴合度"而非"理解正确度"——这正是必须配 `num_hit` 的原因。
4. **拒答标记是关键词匹配**。模型用"根据现有资料无法判断"这类未列入的表述会被漏判，
   当前 12 条拒答题人工复核过，无误判，但换数据集需要重查。
5. **未做人工交叉评分**。全部为自动判分；抽样复核过 calc、readout、unanswerable 三类。
